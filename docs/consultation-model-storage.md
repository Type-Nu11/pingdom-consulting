## 보존하는 저장 계약

- 키: `pingdom-ai-consultation-history-v1:${userId}`. 계정 없는 과거 키를 로그인 계정에 자동 귀속하지 않는다.
- JSON은 `{ activeSessionId, sessions }`를 유지하며 세션 필드·날짜 숫자·선택 값·확정/초안·분석 요청 확정 상태를 임의로 바꾸지 않는다. 알 수 없는 세션 필드도 유지한다. 동의 체크 자체를 새로 영구 저장하지 않는다.
- 읽을 때 최소 식별 필드만 검사하는 기존 정책을 유지한다. 전체 타입 스키마를 검증하는 함수로 강화한 것은 아니다. 읽기 자체는 순서를 재정렬하거나 유효하지 않은 활성 ID를 자동 정리하지 않는다.
- 비어 있거나 손상된 저장소와 접근 실패는 빈 이력을 반환한다. 읽기 함수 자체는 원문을 덮어쓰지 않지만 페이지의 후속 저장까지 원본 보존을 보장하는 것은 아니다.
- 쓰기/직렬화 실패를 전파하지 않고 현재 화면을 유지하는 기존 정책을 유지한다. 반환값은 기존처럼 `undefined`이며 영구 저장 성공을 보장하거나 새 오류 UI를 제공하지 않는다.
- 계정·상담별 PDF 키와 IndexedDB 저장은 기존 분석 기능에 남긴다. 저장 마이그레이션·기존 데이터 삭제·PDF 재생성은 수행하지 않는다.

## 검증

- 이전 코드와 새 코드의 함수 본문을 export 선언만 제외하고 대조했으며, 세 선택 타입/옵션 모듈도 원본과 동일한지 확인했다.
- 신규 단위 검사는 실제 TypeScript 모듈을 Vite SSR로 읽는다. v1 합성 이력 fixture의 전체 필드·알 수 없는 필드·직렬화 형식, 계정별 키, 기존 최소 필드 판정, 손상/차단 저장소, 정렬과 문자열 표현을 고정한다.
- TypeScript AST로 `model`/`storage`의 상대 import 및 재내보내기가 `src/pages`를 역참조하지 않는지 검사한다.
- 최초 브라우저 실행은 import 정리 도중 HMR이 발생해 종료했다. 파일 편집을 멈춘 새 실행에서도 모바일 한 요소의 경계 검사가 실패하여 원본 `main`의 페이지를 임시 Vite load 대역으로 대조했고 같은 종류의 실패를 재현했다.
- 가상 JS 시계 진행만으로 CSS 진입 애니메이션이 끝나지 않는 문제를 확인하여 경계 측정 직전 유한한 CSS 애니메이션을 완료한다. 무한 장식 애니메이션은 그대로 두며, 업종 선택 컨트롤 표시를 기다린 후 측정한다. 경계·문서 너비·내부 가로 스크롤 assertion은 삭제하거나 완화하지 않는다.
